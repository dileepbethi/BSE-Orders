# Design Philosophy

OrderIQ is an Enterprise Procurement Intelligence Platform.

The interface must feel trustworthy, premium, fast, and professional.

Users spend hours reviewing procurement announcements. The UI must reduce fatigue while maximizing information density.

Our inspiration is taken from:

- Linear
- Stripe Dashboard
- Vercel
- Mercury
- Notion
- Bloomberg (modernized)
- Apple Human Interface Guidelines

We intentionally avoid generic admin templates.

---

# Design Principles

1. Consistency over creativity.
2. Simplicity over decoration.
3. Information first.
4. Fast interactions.
5. Enterprise usability.
6. Accessibility by default.
7. Desktop-first experience.
8. Every page should feel connected.

# UX Rules

Maximum three clicks to reach any order.

Every page must have one primary action.

All destructive actions require confirmation.

Save operations provide immediate feedback.

Filters should persist until cleared.

Search should be available globally.

Every page should support keyboard navigation.
